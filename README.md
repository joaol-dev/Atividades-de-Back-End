# Atividades Back End

Repositório destinado ao armazenamento e organização das atividades práticas desenvolvidas durante as aulas de Laboratório de Desenvolvimento Back-end.

## Sobre o repositório

Este repositório foi criado para armazenar e organizar as atividades práticas desenvolvidas durante as aulas de Laboratório de Desenvolvimento Back-End.

O objetivo é registrar a evolução dos conhecimentos adquiridos durante a disciplina, colocando em prática conceitos de programação, estruturas de dados, funções, organização de código, programação orientada a objetos e controle de versão.

As atividades são organizadas em pastas separadas, permitindo que cada exercício possua seus próprios arquivos, códigos e documentação.

## Atividades desenvolvidas

## Menu de Tarefas
Sistema de gerenciamento de tarefas executado pelo terminal, utilizando estruturas de decisão, repetição, listas, dicionários e validação de dados.

Pasta: menu_tarefas/
Arquivo principal: menu_tarefas.py
README da atividade

## Gerenciador de Chamados Internos
Sistema para gerenciamento de chamados internos, trabalhando com listas, dicionários, filtros, atualização por identificador e conjuntos (set).

Pasta: gerenciador_chamados/
Arquivo principal: gerenciador_chamados.py
README da atividade

## Controle de Tarefas
Refatoração de um sistema de tarefas utilizando programação orientada a objetos, classes, métodos, funções e separação de responsabilidades em módulos.

Pasta: controle_tarefas/
Arquivos principais: main.py, tarefa.py e servicos.py
README da atividade

## Pré-requisitos

Para executar as atividades, é necessário ter o Python 3 instalado.

Para verificar a instalação:

python --version

## Execução

Cada atividade possui seu próprio arquivo de execução.

Entre na pasta da atividade desejada e execute o arquivo correspondente.

Exemplo:

cd controle_tarefas
python main.py

Ou:

python3 main.py

As instruções específicas de cada atividade estão disponíveis nos respectivos arquivos README.md.

## Controle de versão

O projeto utiliza Git para controle de versão e acompanhamento das alterações realizadas.

Para registrar alterações:

git add .
git commit -m "descricao da alteracao"
git push

As mensagens de commit devem ser objetivas e descrever a alteração realizada.

Observações
Este é um repositório acadêmico desenvolvido para as atividades da disciplina de Laboratório de Desenvolvimento Back-End.

Algumas atividades utilizam armazenamento temporário em memória. Nesses casos, os dados cadastrados ou alterados são perdidos quando o programa é encerrado.
